# Nuvela Hair Clinic: frontend

React 19 + Vite single-page app with English, Turkish and Arabic (RTL) versions.

```bash
npm install
npm run dev        # development server
npm run build      # production build + sitemap + 404.html
npm run preview    # serve the production build
npm run lint
```

Environment variables are documented in `.env.example`. See the root `README.md` and
`docs/ARCHITECTURE.md` for the full picture.
